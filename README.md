# atlas-precolonial-african-states
Atlas of 19th c. African States

This dataset provides an estimate of the spatial extent of states in precolonial Africa in the 19th century. The data is described in depth in the associated paper - see citation below. The dataset is also available on [dropbox](https://www.dropbox.com/scl/fi/2tx4c7mev9ot0cwaaq9g6/Atlas-of-African-Centralized-States.zip?rlkey=7myvu29k97cahrzx8oplhg8t5&dl=0).

When using this data, please cite:
Wilfahrt, Martha. 2026. [A Precolonial Paradox? Rethinking Political Centralization and its Legacies] (https://doi.org/10.1017/S0003055425101044) American Political Science Review 120(2), pp. 419-438.
